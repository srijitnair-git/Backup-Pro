## Implementation (Tasks 4, 5, 6 — all COMPLETED)
- **Resiliency**: `lib/core/network/retry.dart` (`withRetry`, exponential backoff). Wired into `background_service.dart` around `connect()` and `uploadFile()`. A single file's failure after retries no longer aborts the whole folder — it's skipped and logged, and the folder's `lastSyncTime` is only advanced if every file in the pass succeeded.
- **VPN automation**: `lib/core/network/vpn_manager.dart` + native `MainActivity.kt` MethodChannel (`backup_pro/vpn`) to detect installed VPN apps (WireGuard, Tailscale, OpenVPN Connect, NordVPN, ProtonVPN, ExpressVPN, Surfshark) and launch the user's chosen one. LAN reachability checked via a raw `Socket.connect` to the NAS IP — no new dependency needed. Wired into the sync flow before the SMB connection; aborts with a clear status message if the NAS still can't be reached after retrying. Deleted the old dead `openVpnSettings()` stub and the now-unused `url_launcher` dependency.
- **Found and fixed while wiring this in**: `AndroidManifest.xml` had no `INTERNET`/`ACCESS_NETWORK_STATE` permission at all — SMB sync would have silently failed on a real device regardless of any VPN logic. Also added `<queries>` entries for the 7 VPN packages (Android 11+ package visibility; without it, VPN app detection would always return empty).
- **UI fixes**: Settings screen gained a "Test Connection" button and a "Preferred VPN app" dropdown. Folder selection now stores `{local, remote}` pairs (JSON, replacing the old flat local-path-only list; auto-migrates existing installs) with an editable destination path and a per-folder "Last synced" / "Never synced" status with a cloud icon.
- **Test suite**: found 2 pre-existing failing tests in `ui_test.dart` (asserted UI copy — "Live Transfer", "Select Folders", a checkbox-based folder list — from a mockup that had already been replaced by the real UI) and 1 in `core_test.dart` (asserted old widget provider names before the `AndroidManifest.xml` rename). None were caused by this session's changes; fixed all three to match current reality. Added 2 new tests for `withRetry`. All 6 tests pass. `flutter analyze` clean (info-level lints only, pre-existing). `flutter build apk --debug` succeeds.
