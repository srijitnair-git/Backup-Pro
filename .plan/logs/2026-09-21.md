## FolderSync Pro research
User asked to research FolderSync Pro in depth and "add all the required things." Researched via web search (Tacit Dynamics' official docs at foldersync.io, Play Store listing). Real feature surface is large and mostly out of this project's stated scope (PRD is: personal NAS backup for 3-4 users over SMB, not a general sync tool):
- Multi-provider backends: Dropbox, Google Drive, S3, OneDrive, MEGA, ownCloud, Yandex, FTP/FTPS/SFTP/WebDAV — Backup Pro is SMB-only by design.
- Sync direction per pair: one-way-to-NAS (current), one-way-from-NAS, two-way with conflict resolution.
- Per-pair schedules (not just one global schedule), each with its own connection/notification settings and Wi-Fi-network matching (e.g. only sync this pair on the home SSID).
- File filters: name/type/regex-based include-exclude, not just modified-time.
- Conflict handling policy (skip/overwrite/rename) when both sides changed.
- Versioned/timestamped backup folders (keep N historical copies instead of overwriting).
- PIN/biometric app lock.
- Tasker integration for custom automation triggers.
- In-app file manager (browse/copy/move/delete on either side directly).
Did not start building any of this — flagged to the user as a scope decision (grill) rather than assuming which subset actually matches this app's personal-NAS-backup PRD, since blindly matching a general-purpose competitor's full feature set would blow past what Backup Pro is actually for.
